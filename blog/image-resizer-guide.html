2. Aspect Ratio Lock Kya Hai? Kyu Zaroori Hai?

Sab se badi galti jo log karte hain - Photo ko stretch kar dete hain. Chehra lamba ya mota lagta hai. PPSC interview me is se impression kharab hota hai.

Lock Aspect Ratio ka matlab hai - Width badhao to Height khud ba khud sahi hisaab se badhega. Chehra original jaisa hi rahega.

Example:

Aapki original photo 600x800px hai (3:4 ratio). Agar aap 300x300px (1:1) karoge bina lock ke, to chehra dab jayega. Lock on karke tool khud 300x400px banayega taake ratio sahi rahe. Agar aapko exact 300x300 hi chahiye to Cover (Crop) mode use karo.

3. 3 Fit Modes Ka Farq - Konsa Kab Use Karein?

1. STRETCH (Exact)

Exact width x height jo aap likhoge wahi banega. Photo khinch sakti hai. Kab use karein: Jab portal exact size maang raha ho (e.g., PPSC 300x300).

2. COVER (Crop) - BEST FOR PASSPORT

Photo ko crop karke exact size banayega, chehra sahi rahega. Kab use karein: Passport 35x45mm, Instagram ke liye best.

3. CONTAIN (White BG)

Poori photo dikhegi, side me white background ayega. Kab use karein: Jab photo ka koi hissa katna nahi chahte.

5. DPI Kya Hai? 72 vs 300 DPI

72 DPI: Sirf screen ke liye (Instagram, Facebook, WhatsApp). File size kam hota hai.

300 DPI: Print ke liye (Passport print, CV print, PPSC hard copy). Quality HD hoti hai, file size thoda zyada hota hai. Government jobs ke liye hamesha 300 DPI use karo.
